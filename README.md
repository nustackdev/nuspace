# nuspace

Nu runtime built on Nu. Self-hosted.

A tree of planes, each a group of cells.
The runtime evaluates Nu programs, provides the fabrics they use (nustd.kv, nustd.proxy, nustd.mp_pool, nulog, nustd.ui), and renders a human interface for the ones that opt in.
